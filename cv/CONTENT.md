## Software contributions

- **gwBOB** — Primary Developer · github.com/AnujKankani/BackwardsOneBody
  Open-source, user-friendly Python package implementing the Backwards One Body
  waveform model, with tools for analysis and NR comparison.
- **Einstein Toolkit** — Contributor · einsteintoolkit.org
  Open-source high-performance-computing codebase for numerical relativity.
- **Entity** — Contributor · entity-toolkit.github.io/wiki
  Kokkos-based General Relativistic Particle-in-Cell code for plasma astrophysics.
- **NRPy** — Contributor · github.com/nrpy/nrpy
  Python-based symbolic code-generation toolkit for relativistic astrophysics.
- **LisaWave-JAX** — Co-developer (in development)
  JAX-based LISA data-analysis tools for massive black holes and galactic binaries.
