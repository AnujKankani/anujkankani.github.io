- [x] **`Viz.loop.start()` now honours the visibility gate.** It checked only `running`/`destroyed`, so a tool calling it directly — swsh does, on drag start — could begin a rAF while off-screen or backgrounded. `frame()` caught it one frame later, but the API advertising `start()` did not actually guarantee rule 2.
